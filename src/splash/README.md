# 水波开屏

开屏的实现统一放在本目录。外部只保留 `index.html` 的容器、样式与启动脚本引用，以及 `src/app.js` 首次渲染后的 `finishSplash()` 调用。

- `style.css`：纯色背景、深浅色、退场与错误提示。默认浅灰蓝 `#e8edef`，深色 `#171e25`；修改 `--splash-color` 即可换底色。
- `water.js`：独立编写的 WebGL 涟漪、波面明暗与壁纸折射。无需第三方库或网络资源。
- `index.js`：约 1.55 秒涟漪 + 0.55 秒淡出；监听减少动态效果、页面隐藏，退出时释放画布、纹理与监听器。
- `boot.js`：独立于应用模块的 4 秒恢复机制。应用已渲染则移除遮挡，加载失败则提供重新打开入口。

## 更换壁纸

沿用「外观 → 壁纸」，保存的图片会同时用于桌面和下一次开屏；「恢复默认」回到纯色底。`finishSplash({ wallpaper })` 接收现有本地 JPEG / PNG / WebP 数据，不增加另一份壁纸设置或存储。默认不带图片、文字、花朵。

壁纸作为水面纹理按居中 cover 裁切，波纹使图片轻微折射；纯色模式使用同一波面产生柔和的亮边与阴影。轻触开屏可产生一道涟漪，不延长开屏时间。

## 性能与降级

像素比上限 1.5，画布长边上限 1600，壁纸纹理长边上限 2048。没有 WebGL 时使用背景淡出；系统开启减少动态效果时直接进入应用；图片失败不阻塞进入应用。动画不等待模型、连接或其他网络请求，也不在后台持续运行。

旧的 yuria 字样、专用字体、水雾素材和旧预览已移除。以后替换开屏视觉时，优先只改本目录。
