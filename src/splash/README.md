# 水波开屏

开屏的实现统一放在本目录。外部只保留 `index.html` 的容器、样式与启动脚本引用，以及 `src/app.js` 首次渲染后的 `finishSplash()` 调用。

- `style.css`：纯色背景、深浅色、退场与错误提示。默认浅灰蓝 `#e8edef`，深色 `#171e25`；修改 `--splash-color` 即可换底色。
- `surface.js`：双缓冲水面高度场、点按与划动扰动。
- `gesture.js`：按参考的移动距离阈值触发划动扰动。
- `water.js`：WebGL 波面明暗、反光、近似聚光与壁纸折射。无需第三方库或网络资源。
- `index.js`：手动点击「进入」后用 0.55 秒淡出；监听减少动态效果、页面隐藏，退出时释放画布、纹理与监听器。
- `boot.js`：独立于应用模块的 4 秒恢复机制。交互入口接好后即解除超时，不打断玩水；启动异常时移除遮挡或提供重新打开入口。

## 更换壁纸

在「外观 → 开屏壁纸」上传 JPG、PNG 或 WebP，压缩后本机保存，下次打开时显示；「恢复默认」回到纯色水面。主页壁纸单独设置。旧数据首次加载时会将原壁纸沿用为开屏壁纸，两张壁纸均随 JSON／ZIP 备份保存。

视觉顺序为：背景 → 进入入口 → 水波。壁纸按居中 cover 裁切，与入口的外观一起绘入底层纹理，水波同时折射壁纸和入口。原生按钮位于水波画布下方，画布不拦截点击；键盘焦点也绘入水下纹理，触摸与键盘均可进入。

动态以 Whynotmetoo/water-ripples 的 `0d86747` 为行为参照：点按产生半径 6、强度 2.2 的扰动；移动超过 2 CSS 像素产生半径 2.4、强度 0.45 的扰动，鼠标悬停也可拨水。每隔 0.4–1.7 秒出现一次细小环境涟漪。折射、方向性明暗、波峰高光、移动日光带与光斑采用对应参数。坐标从左上起算，多指分别记录位置。

## 性能与降级

水面宽 160 格，高度随屏幕比例限制在 90–288 格，边缘固定。以固定 60 Hz 步长计算双缓冲波动，衰减系数 0.979，避免高刷新率屏幕加速。上传单通道高度纹理，在着色器中计算梯度。开屏期间持续模拟与绘制，点击进入或切到后台时释放资源。像素比上限 1.5、画布长边上限 1600。无 WebGL 时保留原生入口，减少动态效果设置直接跳过开屏。

参考实现：https://github.com/Whynotmetoo/water-ripples/tree/0d867471f2c3dcd8496126e04a87900967a929f1 。本项目独立实现相应算法，使用用户上传的开屏壁纸。测试固定输入对应的高度纹理与参考实现逐字节一致。

旧的 yuria 字样、专用字体、水雾素材和旧预览已移除。以后替换开屏视觉时，优先只改本目录。
