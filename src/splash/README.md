# 水波开屏

开屏的实现统一放在本目录。外部只保留 `index.html` 的容器、样式与启动脚本引用，以及 `src/app.js` 首次渲染后的 `finishSplash()` 调用。

- `style.css`：纯色背景、深浅色、退场与错误提示。默认浅灰蓝 `#e8edef`，深色 `#171e25`；修改 `--splash-color` 即可换底色。
- `surface.js`：连续水面高度场、手指轨迹扰动与池壁反射。
- `water.js`：WebGL 波面明暗与壁纸折射。无需第三方库或网络资源。
- `index.js`：手动点击「进入」后用 0.55 秒淡出；监听减少动态效果、页面隐藏，退出时释放画布、纹理与监听器。
- `boot.js`：独立于应用模块的 4 秒恢复机制。交互入口接好后即解除超时，不打断玩水；启动异常时移除遮挡或提供重新打开入口。

## 更换壁纸

沿用「外观 → 壁纸」，保存的图片会同时用于桌面和下一次开屏；「恢复默认」回到纯色底。`finishSplash({ wallpaper })` 接收现有本地 JPEG / PNG / WebP 数据，不增加另一份壁纸设置或存储。默认使用纯色背景，只保留「进入」入口。

视觉顺序为：背景 → 进入入口 → 水波。壁纸按居中 cover 裁切，与入口的外观一起绘入底层纹理，水波同时折射壁纸和入口。原生按钮位于水波画布下方，画布不拦截点击；键盘焦点也绘入水下纹理，触摸与键盘均可进入。

点按激起涟漪，按住划动会沿完整轨迹拨动水面，支持多指交叠。四边作为池壁，波纹碰到边缘会反射并逐渐衰减；松手后水面继续晃动，直到平静。点击「进入」结束开屏。

## 性能与降级

像素比上限 1.5，画布及合成纹理长边上限 1600，同时遵循设备纹理尺寸限制。高度场短边约 100 格、长边最多 240 格，以固定时间步长计算；画面使用平滑插值和打包法线纹理，无需浮点纹理扩展。水面平静后停止计算和绘制，新触摸会唤醒。窗口尺寸改变时重新建立水面。没有 WebGL 或图形上下文丢失时仍保留可点击的原生入口；系统开启减少动态效果时直接进入应用；图片失败不阻塞进入。动画不等待模型、连接或其他网络请求，也不在后台持续运行。

旧的 yuria 字样、专用字体、水雾素材和旧预览已移除。以后替换开屏视觉时，优先只改本目录。
