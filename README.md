# 尘 · Chenxin

手机优先的私人聊天前端。第一版只做界面和本机交互，不启动后端、不调用模型、不执行插件。

[开屏预览](docs/preview-splash.webp) · [浅色主页预览](docs/preview-home.webp) · [夜间主页预览](docs/preview-night.webp)

## 运行

需要 Python 3（仅用来提供静态文件服务，不是应用后端）。

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

打开 http://127.0.0.1:5173 。也可以运行 `npm start`。不要直接双击 index.html：浏览器会限制本地 ES 模块。

- 会话：新建、切换、删除、本机草稿保存；会话列表从对话页顶部进入。
- 记忆：手动添加、搜索、编辑、删除，以及收藏对话中的消息；短期（1/7/30 天）、永久分类。到期保留在“已到期”，不自动删除。
- 设置：外观、纪念日、小组件、角色、API、MCP/插件、数据储存和用量。

- 图标采用 Lucide，同属 React Icons 收录的图标系列；许可见 THIRD_PARTY_NOTICES.md。

## 功能边界

这仍是前端原型。消息只保存在本机，不会发给模型；没有模拟 AI 回复。记忆由用户手动收藏，尚未自动提取或检索到模型上下文。API 密钥输入暂时禁用，模型和插件配置不会建立网络连接。没有账号登录、订阅额度、附件、语音、MCP 执行、云同步或后台通知。用量页只显示本机数据数量，不生成 Token 或费用数字。

玻璃效果是网页用透明度、背景模糊、反光边缘模拟的视觉风格，并非苹果系统原生材质；不支持背景模糊的浏览器会降级为实色背景。

本机数据使用同一来源下的 localStorage。清除站点数据会丢失记录；需要保留时请先导出。导入会替换当前数据，需要确认。图片限制输入 12MB，并缩小压缩后保存；备份限制 6MB，最终仍取决于浏览器可用存储。原型还没有生成 APK，也未实现 PWA 安装和离线缓存。

## 结构

```text
index.html          应用入口
src/app.js          导航、事件、图片处理
src/views.js        主页、对话、记忆与设置页面
src/store.js        会话、配置与本机存储
src/icons.js        图标
src/style.css       响应式布局、主题
legacy/             重构前的桌面程序（仅存档，不能独立运行）
docs/architecture.md 后续接口与移动打包路线
```

纯静态 ES 模块，无前端构建依赖；访问页面不需要下载 CDN 字体或图标。后续接入模型时将网络适配器与界面分离；移动端可评估 Capacitor 打包或迁移原生 UI。

设计参考：Tidal Echo 的轻柔聊天氛围；Operit/Operit2 的扩展能力；RikkaHub 的模型与角色配置。此版应用代码独立编写，没有复制这些项目的实现或图片；Lucide 图标数据按其开源许可使用。

### 沉浸式对话与收藏面板

对话页隐藏主导航，顶部返回主页；`✦` 打开模型选择，更多菜单包含会话列表与角色设定。模型选择按会话保存，目前仅有设置中配置的模型和会话原先保存的选项，不发起模型请求。

输入框随文字增高，最多六行，超出后内部滚动。左侧 `＋` 添加图片或文件，笑脸打开「表情包 / 颜文字」；颜文字可添加、编辑、删除、收藏，并在光标位置插入，最近使用按时间排序。图片表情包可从 JPG、PNG、WebP 导入，收藏与消息图片会随 JSON 备份导入导出。现有旧数据自动补齐收藏字段。

附件一次最多六项、单项不超过 10MB。图片压缩后在本机保存；普通文件只保存名称、大小和类型，**不保存文件内容，也不上传或让模型读取**。输入中的附件在刷新前为临时草稿；发送按钮只保存本机消息。语音、模型服务、MCP 运行和跨设备同步尚未接入。

### 侧边栏与会话列表

对话页左上角打开侧边栏；上方显示用户头像与昵称，提供「对话、主页、记忆、设置」入口，下方分为置顶聊天和历史对话，底部固定新建按钮。点击「对话」进入完整会话列表，可以按标题或消息正文搜索、切换时间排序、置顶、重命名和删除；置顶始终排在前面并随备份保存。侧栏可通过收起按钮、遮罩或 Escape 关闭。对话页和完整会话列表隐藏底栏，其他页面保留底栏导航。

附件、表情收藏与模型选择面板使用从屏幕底部升起的抽屉窗口，覆盖输入框，背景模糊并暂时不可交互；可点遮罩、关闭按钮、Escape 或从拖拽条向下拖动收起（面板随手指移动，短距离拖动会回弹；遵循系统减少动态效果设置）。选中颜文字或图片表情后返回输入框继续编辑。附件面板增加相机入口（在支持的手机浏览器中请求拍摄，桌面浏览器可能使用文件选择器）和 MCP 配置入口。
