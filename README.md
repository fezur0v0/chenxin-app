# 尘 · Chenxin

手机优先的私人聊天前端。第一版只做界面和本机交互，不启动后端、不调用模型、不执行插件。

## 运行

需要 Python 3（仅用来提供静态文件服务，不是应用后端）。

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

打开 http://127.0.0.1:5173 。也可以运行 `npm start`。不要直接双击 index.html：浏览器会限制本地 ES 模块。

## 已实现

- 手机四页导航、桌面侧栏、浅色与深色主题。
- 新建、切换、删除本机会话；输入消息、记录时间、自动会话标题。
- 角色名称与设定编辑。
- 模型接口类型、地址和模型 ID 配置。
- 插件/MCP 配置添加、编辑、删除；地址校验。
- 本机保存、JSON 导出；未连接状态提示。
- 中文输入法兼容：Enter 保存，Shift+Enter 换行，组合输入期间不提交。

## 第一版边界

聊天里的消息是本机草稿，不会发给模型，也没有模拟 AI 回复。API 密钥输入暂时禁用。模型配置和插件配置都不会建立网络连接。无账号登录、订阅额度接入、附件、语音、插件执行、云同步、备份导入或后台通知。

本机数据使用当前浏览器来源的 localStorage，清除站点数据会丢失记录；需要保留时请先导出。导出包含私人聊天和角色设定。浏览器原型不是已安装的 APK，也未实现 PWA 安装与离线缓存。

## 结构

```text
index.html          应用入口
src/app.js          页面与交互
src/store.js        会话、配置与本机存储
src/icons.js        图标
src/style.css       响应式布局、主题
legacy/             重构前的桌面程序（仅存档，不能独立运行）
docs/architecture.md 后续接口与移动打包路线
```

纯静态 ES 模块，无前端构建依赖。后续接入模型时将网络适配器与界面分离；移动端可评估 Capacitor 打包或迁移原生 UI。
