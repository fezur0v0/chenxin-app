# 尘 · Chenxin

手机优先的私人聊天前端。第一版只做界面和本机交互，不启动后端、不调用模型、不执行插件。

[浅色主页预览](docs/preview-home.webp) · [夜间主页预览](docs/preview-night.webp)

## 运行

需要 Python 3（仅用来提供静态文件服务，不是应用后端）。

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

打开 http://127.0.0.1:5173 。也可以运行 `npm start`。不要直接双击 index.html：浏览器会限制本地 ES 模块。

## 当前版本（v0.2）

- 默认打开主页；底部只有主页、对话、记忆、设置。
- 半透明玻璃组件与浮动导航，背景模糊/透明度可调。
- 顶部纪念日：开始日期、双方名字、头像、描述可修改。
- 主页小组件：今天、便签、心情、记忆收藏；支持显隐、调整顺序和内容编辑。
- 外观：主题色、夜间模式、自定义壁纸、用户头像和 AI 头像。图片解码并缩小后保存在本机。
- 会话：新建、切换、删除、本机草稿保存；会话列表从对话页顶部进入。
- 记忆：手动添加、搜索、编辑、删除，以及收藏对话中的消息；短期（1/7/30 天）、永久分类。到期保留在“已到期”，不自动删除。
- 设置：外观、纪念日、小组件、角色、API、MCP/插件、数据储存和用量。
- 完整 JSON 备份导出/恢复，兼容 v0.1 的会话数据。
- 图标采用 Lucide，同属 React Icons 收录的图标系列；许可见 THIRD_PARTY_NOTICES.md。

## 功能边界

这仍是前端原型。消息只保存在本机，不会发给模型；没有模拟 AI 回复。记忆由用户手动收藏，尚未自动提取或检索到模型上下文。API 密钥输入暂时禁用，模型和插件配置不会建立网络连接。没有账号登录、订阅额度、附件、语音、MCP 执行、云同步或后台通知。用量页只显示本机数据数量，不生成 Token 或费用数字。

玻璃效果是网页用透明度、背景模糊、反光边缘模拟的视觉风格，并非苹果系统原生材质；不支持背景模糊的浏览器会降级为实色背景。

本机数据使用同一来源下的 localStorage。清除站点数据会丢失记录；需要保留时请先导出。导入会替换当前数据，需要确认。图片限制输入 12MB，并缩小压缩后保存；备份限制 6MB，最终仍取决于浏览器可用存储。原型还没有生成 APK，也未实现 PWA 安装和离线缓存。

## 结构

```text
index.html          应用入口
src/app.js          导航、事件、图片处理
src/views.js        主页、对话、记忆与设置页面
src/store.js        会话、配置与本机存储
src/icons.js        图标
src/style.css       响应式布局、主题
legacy/             重构前的桌面程序（仅存档，不能独立运行）
docs/architecture.md 后续接口与移动打包路线
```

纯静态 ES 模块，无前端构建依赖；访问页面不需要下载 CDN 字体或图标。后续接入模型时将网络适配器与界面分离；移动端可评估 Capacitor 打包或迁移原生 UI。
