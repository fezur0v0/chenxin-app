# 尘 · Chenxin

手机优先的私人聊天前端。第一版只做界面和本机交互，不启动后端、不调用模型、不执行插件。

[开屏预览](docs/preview-splash.webp) · [浅色主页预览](docs/preview-home.webp) · [夜间主页预览](docs/preview-night.webp) · [App 桌面](docs/preview-apps.webp) · [夜间 App 图标](docs/preview-apps-dark.webp) · [外观 App](docs/preview-app-appearance.webp)

## 运行

需要 Python 3（仅用来提供静态文件服务，不是应用后端）。

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

打开 http://127.0.0.1:5173 。也可以运行 `npm start`。不要直接双击 index.html：浏览器会限制本地 ES 模块。

## 数据与备份

系统设置 → 数据与备份提供：

- **完整 ZIP**：记录、相册图片、世界书、预设、界面配置，以及本机可用的音乐和语音原文件。打包完成后显示内容数量与大小，再下载；原文件缺失时明确列出，按钮改为「下载可用内容」。
- **轻量 JSON**：兼容原有 v1/v2 数据，包含文字、图片和配置，不打包音频原文件。
- **恢复预览**：先检查格式、清单、大小和 SHA-256，展示当前与备份中的内容数量；确认覆盖前可保存当前完整快照。恢复成功后回到数据与备份，不自动播放音频。
- **本机快照**：默认在打开／回到 App 时每天检查一次，支持手动创建、恢复、下载和删除，保留最近 3／5／10 份，默认 5 份。每日标记独立保存，清理旧快照后当天不会重复自动生成。空白新账号不生成无内容的自动快照。

恢复音频先写入新 ID，所有文件成功后才提交记录；写入失败或取消时清理本次新文件，保留原记录与原音频。旧 JSON 恢复沿用本机已有音频 ID。完整 ZIP 会重新映射歌单、队列和共享语音引用，备份里缺失的音频不会误用目标浏览器中同名 ID 的文件。已替换记录引用的旧音频暂不自动清理，重复恢复可能增加本机占用。

本机快照保存在当前浏览器，会随站点数据一起清除；下载的 ZIP 才适合迁移设备。网页关闭后不保证定时备份，目前没有服务器同步。聊天样式预览使用独立的内存快照，不读取或覆盖正式快照。

[完整备份预览](docs/preview-backup-export.webp) · [恢复预览](docs/preview-backup-restore.webp) · [本机快照](docs/preview-backup-snapshots.webp)。格式与后端接入边界见 [备份格式](docs/BACKUP_FORMAT.md)。ZIP 使用随项目内置的 fflate 0.8.2（MIT），不依赖外部 CDN 或构建步骤。

## 图库与相册

进入图库先显示相册分类：所有照片、我上传的、对话珍藏，以及自建相册。点进相册后按照片日期倒序分组，每行固定四张 1:1 缩略图；点开大图，可左右切换，并编辑名称、备注和日期。上传时默认取文件修改日期，可自行校正，不假定它是拍摄时间。

- 相册支持新建、改名、描述和选择封面；删除相册会保留照片。
- 选择模式支持多选、全选、批量移动、移出自建相册和删除，也可新建相册后直接移入。
- 图片来源仅限主动上传，以及模型明确请求收藏的用户聊天照片。不再自动汇集壁纸、头像、所有聊天图片或表情包；没有网址导入入口。
- 相册、照片和来源随记录 JSON／完整 ZIP 备份保存。上传解码失败或本机空间不足会回滚本批次，不部分写入；编辑失败保留表单。

模型收藏接口为 `saveConversationPhoto({sessionId,messageId,attachmentId,albumId?,name?,caption?})`，从 `src/app.js` 导出：仅接受已发送的用户照片；按来源去重，保存独立副本，删除原聊天后仍保留珍藏。返回 `{photo,created}`，验证或存储失败返回 `null`。目前没有真实模型接入，已接好本机执行接口，尚不会由 AI 自动发起。

## 表情包与图片消息

图片和表情包发出后只展示图片，备注仍保存在消息数据中，普通文件附件继续显示文件名。顶部保留「表情包／颜文字」分段切换条；下方左侧搜索栏替代「全部／收藏／最近」，右侧保留管理和添加。分类继续使用轻量按钮。表情包面板支持：

- 上传 JPG、PNG、WebP、GIF 并填写表情含义，保留透明底，GIF 保留原动画。
- 粘贴「含义：HTTPS 图片网址」，或从 TXT、JSON、DOCX 导入；预览后确认，重复项跳过，错误内容不部分导入。
- 自定义分类，长按／右键分类可重命名或删除，也可用当前分类旁的更多按钮操作。删除分类将表情包移至未分类。
- 管理模式中多选、全选当前列表，批量移动或删除。删除表情包不影响已发出的图片。

颜文字也支持独立的自定义分类、长按重命名／删除分类，以及多选移动／删除；新增和编辑时可选择分类，删除分类保留内容并移到未分类。

备注、两套分类、收藏与使用记录随记录 JSON／完整 ZIP 备份保存。当前没有真实模型接入，备注为后续上下文理解保留。网址表情保留原链接，不将远程图片下载进备份。实际预览：[表情包面板](docs/preview-stickers.webp)、[批量管理](docs/preview-stickers-manage.webp)、[导入](docs/preview-stickers-import.webp)、[颜文字管理](docs/preview-kaomoji-manage.webp)。

## 聊天里的思考、语音与引用

- 思考摘要：AI 消息上方的轻量入口，只在有摘要或明确思考状态时显示；耗时取真实元数据。点开透明玻璃抽屉，分段阅读、复制摘要，可拖动横条收起。
- 语音条：点输入框右侧的麦克风按钮选择本机音频（10MB、10 分钟以内），以真实波形与时长显示，支持播放／暂停、进度拖动、结束重播。服务提供转写文字时可单独展开；当前不自动识别或合成语音。聊天语音与音乐播放互相协调。
- 引用：长按／右键消息选择「引用」，输入框上方预览并可取消；发送后点击引用定位原消息并高亮。引用保存当时的摘要，原消息删除后保留引用并标明无法定位，不复制图片二进制。

语音元数据与引用随 JSON 备份保存，音频文件单独保存在 IndexedDB；完整 ZIP 备份会打包可用原文件，换浏览器恢复后可以直接播放。轻量 JSON 不含原文件，缺失时可以重新选择音频补回。图片和表情包仍不显示文件名。实际界面：[聊天细节](docs/preview-chat-details.webp)、[思考摘要](docs/preview-reasoning-sheet.webp)、[语音条](docs/preview-chat-voice.webp)、[引用草稿](docs/preview-chat-reply.webp)。预览使用临时演示消息和测试音频，默认会话不会添加示例回复。

聊天侧边栏新增「聊天样式预览」，也可在页面地址后加 `?preview=chat` 直接打开。可以展开思考摘要、播放测试音、引用与发送示例消息，并切换昼夜；消息、偏好与音频仅留在预览内存中，刷新重置，退出后保留原聊天。预览麦克风仍用于选择音频文件，尚未接入录音。

## 功能边界

这仍是前端原型。消息只保存在本机，不会发给模型；没有模拟 AI 回复。记忆由用户手动收藏，尚未自动提取或检索到模型上下文。API 密钥输入暂时禁用，模型和插件配置不会建立网络连接。没有账号登录、订阅额度、真实附件上传／模型读取、AI 语音合成／转写、MCP 执行、云同步或后台通知。用量页只显示本机数据数量，不生成 Token 或费用数字。

玻璃效果是网页用透明度、背景模糊、反光边缘模拟的视觉风格，并非苹果系统原生材质；不支持背景模糊的浏览器会降级为实色背景。

记录与图片使用同一来源下的 localStorage，音频与本机快照使用 IndexedDB。清除站点数据会丢失记录；需要保留时请先下载完整备份。恢复前会校验并展示内容，确认后替换当前数据。图片限制输入 12MB（图库上传 10MB），并缩小压缩后保存；JSON 数据上限 16MB，ZIP 及解压总量上限 256MB，最终仍取决于浏览器可用空间。原型还没有生成 APK，也未实现 PWA 安装和离线缓存。

### 沉浸式对话与收藏面板

对话页隐藏主导航，顶部左侧打开侧边栏；`✦` 打开模型选择，点击对方资料可编辑角色设定。模型选择按会话保存，目前仅有设置中配置的模型和会话原先保存的选项，不发起模型请求。

输入框默认单行，依次为 `＋`、消息输入、语音、表情、发送；随文字增高，最多六行，超出后内部滚动。左侧 `＋` 添加图片或文件，麦克风选择本机音频，笑脸打开「表情包 / 颜文字」；颜文字可添加、编辑、删除、收藏，并在光标位置插入，最近使用按时间排序。图片表情包可上传 JPG、PNG、WebP、GIF 并填写备注，也可从文字、TXT、JSON、DOCX 导入网址表情；收藏、分类与消息图片随 JSON 备份导入导出。现有旧数据自动补齐收藏字段。

附件一次最多六项、单项不超过 10MB。图片压缩后在本机保存；普通文件只保存名称、大小和类型，**不保存文件内容，也不上传或让模型读取**。输入中的附件在刷新前为临时草稿；发送按钮只保存本机消息。AI 语音合成／转写、模型服务、MCP 运行和跨设备同步尚未接入。

### 侧边栏与会话列表

对话页左上角打开侧边栏；上方显示用户头像与昵称，提供「对话、主页、记忆、设置」入口，下方分为置顶聊天和历史对话，底部固定新建按钮。点击「对话」进入完整会话列表，可以按标题或消息正文搜索、切换时间排序、置顶、重命名和删除；置顶始终排在前面并随备份保存。侧栏可通过收起按钮、遮罩或 Escape 关闭。所有非桌面页面都隐藏 Dock；记忆、设置和独立 App 左上可返回桌面，聊天和会话列表保留侧栏导航。所有 App 的返回按钮由共用页头固定到同一坐标，滚动时保持在顶部；页头背景完全透明，不添加填充、边框、模糊或降级遮罩。音乐的返回／收起沿用原来的转向动画。

附件、表情收藏、模型选择和思考详情使用从屏幕底部升起的抽屉窗口，与音乐的播放队列、歌曲编辑、歌单编辑，以及主页小组件、日记、世界书与预设的编辑面板共用玻璃材质、顶部横条、圆角和间距。抽屉没有右上角 ×；可点顶部横条、遮罩、Escape 或向下拖动横条收起，短距离拖动会回弹；关闭后恢复焦点，遵循系统减少动态效果设置。[心情编辑](docs/preview-home-mood-drawer.webp) · [日记编辑](docs/preview-diary-drawer.webp)。聊天抽屉覆盖输入框，背景模糊并暂时不可交互；选中颜文字或图片表情后返回输入框继续编辑。附件面板增加相机入口（在支持的手机浏览器中请求拍摄，桌面浏览器可能使用文件选择器）和 MCP 配置入口。

聊天消息支持长按、右键或键盘 Shift+F10 打开玻璃菜单。用户消息可复制、引用、编辑、回滚至此、创建分支和删除，AI 消息可复制、引用、创建分支和删除。回滚保留当前消息并移除后续消息；分支复制至当前消息，原会话保留。编辑仅修改文本并保留附件，不重新生成已有回复。

AI 消息的「思考摘要」打开底部抽屉，显示服务明确提供的 `reasoningSummary`；没有摘要且未处于思考状态时隐藏入口，不生成或模拟思维链。该字段、实际耗时和引用随本机备份保留。目前尚未连接模型服务。

主页每页 4×6，格子宽高相等。纪念日占 4×2，日历、便签、心情和记忆占 2×2，App 图标占 1×1。长按/右键菜单可单独编辑组件内容或进入主页布局编辑；使用拖拽和边缘停留跨页移动，支持新增页、滑动与圆点切换、移除和重新添加，键盘使用 Alt+方向键。默认第二页展示六个 App，旧布局保持原顺序，满页会阻止移动，取消拖动不保存。App 与底部入口图标使用官方免费 Nucleo Glass SVG，日间灰黑玻璃、夜间银白玻璃，统一圆角磨砂外框与大小；提白的乳白／深灰底、柔亮边缘和 14px 背景模糊独立固定，不随外观滑块变化。

交互动效覆盖按钮按压、页面切换、侧边栏、弹窗、设置展开、选中反馈及主页组件换位。所有新增动效遵循系统减少动态效果偏好。

每个 App 的界面与样式可在 GitHub 的 [`src/apps/`](src/apps/README.md) 下独立管理，例如 `src/apps/appearance/view.js` 和 `style.css`；导航、主题与数据共享，后续逐个完善功能。

各页面返回按钮统一使用 `src/ui.js` 的 `backButton()`：无背景、无边框，20px 箭头配 44×44px 点击区域，沿用昼夜文字颜色与键盘焦点。音乐页的向下收起状态共用同一个组件，保留平滑转向与减少动态效果支持；统一样式在 `src/navigation.css`，不再在每个 App 页头重复定义。

外观中的背景模糊作用于小组件、聊天、侧栏与弹窗等玻璃区域，支持 0–40px；桌面 App 与底部入口图标的材质独立固定。主页翻页只更新页内内容与分页圆点，保留壁纸/底栏，使用 140ms 的纯位移动画，减少切页时玻璃层闪烁。

音乐文件保存在当前浏览器的本机储存中，JSON 备份包含歌单和歌曲信息；换设备恢复后需要重新选择音频文件。默认曲库为空，未接入网易云或其他音乐服务。

黑胶详情页在页头下方展示双方头像、渐隐耳机线及距离／一起听时长，唱片与播放控件向下协调排列。没有服务数据时距离和时长显示短横；不展示旧的小头像陪伴文字或「本机音乐」页脚。实际预览见 [播放器](docs/preview-music-player.webp)、[播放队列](docs/preview-music-queue.webp)、[歌曲编辑](docs/preview-music-editor.webp) 和 [聊天表情抽屉](docs/preview-expression-sheet.webp)。

### 世界书与预设

世界书按书库、条目列表、编辑抽屉组织，支持新建、搜索、改名、删除、条目开关、关键词／常驻／语义标记，以及注入位置、顺序、深度和身份配置。预设按聊天补全的提示词编排设计：支持多份预设、默认配置选择、提示词开关与排列位置、System/User/Assistant 身份、聊天内注入配置，以及独立的生成参数页签。原有角色资料保留在角色设置中。

可导入酒馆世界书 `entries` 格式与聊天补全 `prompts`／`prompt_order` 核心格式，并单独导出 JSON；预设只导入提示词、编排和支持的生成／格式参数，不导入连接地址、密码和请求头。世界书未编辑的高级字段与提示词条目元数据会保留；预设的其他顶层服务商选项不在本轮兼容范围内。书库／预设各最多 60 份，单个文件最多 1.5 MB，编辑正文最多 32000 字。数据随完整备份保存，旧备份默认空列表，不预置演示内容。

目前这些是本机配置管理；条目触发、宏展开、正则执行、向量检索、作用域绑定、模型请求编排与文本补全模板仍待后续接入。启用开关表示配置状态，尚不改变 AI 回复。
