# moom 默认消息样式与区域约定

本次实现的是默认阅读样式，不是完整的 HTML/CSS 编辑器。
样式入口：`src/apps/moom/default.css`，在 moom 基础布局 CSS 之后加载。

## 预览

正常启动项目后打开：

`http://127.0.0.1:5173/?preview=moom`

这是现有的独立场景预览，使用内存状态，不修改正式聊天。示例中包含头像、楼层、消息时间、对白、动作、强调和一个思考抽屉。抽屉内容明确标注为界面演示，不是真实模型思考。

## 当前默认设计

- 克制的文档阅读布局，没有大块消息气泡。
- 每条消息前显示双列玻璃状态栏：左边头像、下方名字；右边依次为楼层、自定义文字、真实发送时间。淡描边和留白保留简约韩系 ins 风。
- 点击自定义文字打开编辑抽屉，最多 500 字。按场景及用户／AI 分别保存，同一角色消息共用；留空显示编辑提示，纯展示，不写入消息正文或提示词。
- 楼层按原场景记录顺序计数，每个 entry 是一楼。收藏及筛选入口已移除；旧收藏标记仅为备份兼容保留。消息间以留白区分，不画分割线。
- 台词、动作和强调有独立样式。普通正文继承 body 的字体、颜色、字号和行距。
- 有服务提供的思考字段或开头的 `<think>...</think>` 时，显示一个小入口，点击进入共享底部抽屉。
- 用户输入的思考标签仍是正文，不会变成 AI 思考入口。
- 阅读页直接从消息开始，不再展示旧的整幕「场景设定」卡片和重复的开场备注。既有资料保留，仍可从「＋」或「…」菜单编辑，邀请函继续使用开场备注。
- 思考入口不带右侧箭头，点击文字区域仍可通过底部抽屉查看对应消息。
- 缺少思考数据时不生成占位思考或虚构耗时、Token 数量。

## 稳定区域名称

通过 `data-moom-part` 定位。自定义 CSS 编辑器后续可以复用这些名称。

| 名称 | 固定标识 | 所在位置 |
| --- | --- | --- |
| 整个 moom 界面 | screen | moom 根节点 |
| 顶部栏 | header | 顶部角色资料与菜单 |
| 阅读区域 | reading | 可滚动正文 |
| 输入区域 | composer | 底部输入控件 |
| 整条消息 | message | 一条 entry |
| 思考入口 | thinking-trigger | 有思考内容时出现 |
| 思考内容 | thinking-content | 底部抽屉里，位于 moom 根节点外 |
| 消息状态栏 | status | 头像、名字、楼层、发送时间 |
| 名字 | name | 消息头 |
| 楼层 | floor | 消息头 |
| 时间 | time | 原始 entry.time，以本地 24 小时显示 |
| 自定义文字 | custom-text | 状态栏右列中间，点击编辑 |
| 正文 | body | 消息正文容器 |
| 台词 | dialogue | 成对引号内或旧 dialogue 类型内容 |
| 动作 | action | 单星号内或旧 act 类型内容 |
| 强调 | emphasis | 双星号内容 |
| 行内代码 | inline-code | 反引号内的文字 |

折叠栏的 `fold` 为后续预留，本次没有接入自定义 HTML 折叠组件。
`data-moom-role="assistant"` / `data-moom-role="user"` 可区分两类消息。
`data-moom-skin="default"` 标记当前默认皮肤。

## 默认 CSS 变量

在 moom 根节点调整以下变量：

- `--moom-body-color`：正文颜色。
- `--moom-dialogue-color`：台词颜色。
- `--moom-action-color`：动作颜色。
- `--moom-meta-color`：消息头和思考入口颜色。
- `--moom-body-font`：正文字体。
- `--moom-body-size`：正文字号。
- `--moom-body-leading`：正文行高。
- `--moom-message-gap`：消息间距。
- `--moom-status-surface`：消息状态栏的玻璃底色。
- `--moom-status-rim`：消息状态栏及头像的细描边。
- `--moom-status-radius`：消息状态栏圆角。

默认值来自 app 现有的主题和字体变量，跟随明暗主题。

## 原文和显示

`message.js` 负责显示用的思考分离、引号、单星和双星排版。模板不更改原始 entry.text，不添加模型调用，不注入提示词，也不把 CSS 发给模型。

只解析消息开头的思考块，未闭合的开头思考块暂不显示为正文；普通提及或代码示例中的思考标签保持原样。可选 `reasoningSummary` 字段随 normalizeMoom 保留，不给旧记录强行添加空字段。

普通模型文本中的 HTML 继续转义。本次不支持直接执行或渲染任意模型 HTML。开放组件模板、CSS 编辑器、导入导出和按场景选择皮肤属于后续工作。
