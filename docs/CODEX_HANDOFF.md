# 给云端 Codex 的项目交接说明

这是一份背景交接，先理解项目并等待用户下一项具体任务；不要据此一次性重构整个仓库或接入全部服务。

## 项目与目标

- GitHub：`fezur0v0/chenxin-app`，主要分支 `main`。
- 这是欣欣的私人 AI 陪伴聊天 app，先完成手机优先的界面和交互，再逐步接入真实服务，最终希望可以像手机 app 一样使用。
- 仓库与旧界面仍有「尘 / Chenxin」命名，开屏文字是小写 `yuria`。这些名称没有统一重命名决定，不要自行批量替换。
- 目标包括：多服务商 API、角色配置、短期与永久记忆、附件、表情包/颜文字、语音、MCP/插件，以及未来跨设备使用。
- 用户也希望研究能否登录 ChatGPT / Claude 账号使用订阅额度。这只是待调研需求，尚未实现，也没有选定账号接入方案；不能直接把订阅等同于 API 额度，或假设任意登录方式可用。
- 参考：Tidal Echo 的轻柔私人聊天氛围，Operit / Operit2 的扩展能力，RikkaHub 的模型与角色配置。参考地址：
  - https://github.com/anhe2021212-spec/Tidal_Echo
  - https://github.com/AAswordman/Operit
  - https://github.com/AAswordman/Operit2
  - https://github.com/rikkahub/rikkahub
  这些项目不是本仓库的依赖；在阅读其实现或复用代码时另行检查许可证。

## 已确认的视觉方向

- 清透、半透明、克制的 iOS 液态玻璃风格。用网页材质模拟，不是系统原生 Liquid Glass。
- 用户觉得花哨的装饰太多，希望柔和、留白、统一的图标。桌面 App 与底部四个入口统一使用官方免费 Nucleo Glass SVG，内部控件仍使用 Lucide／React Icons。来源与许可见 THIRD_PARTY_NOTICES.md 和 assets/licenses/nucleo-glass.txt，无需换框架。
- 配色走主题变量，支持夜间模式：炭灰表面、柔白文字，全屏壁纸 brightness(.56) 与暗色遮层；聊天、抽屉、菜单、底栏和主页遵循同一深色材质。纪念日数字/日期/气泡文字、头像占位文字和日历时间/日期/星期在日间固定为深灰蓝 #465366；夜间使用主题预设原色；其余正文与辅助文字也轻微随主题色变化。预设色按用户示例替换为天蓝 `#8dc3f0`（第一位）、樱粉 `#f2a7be`、蜜桃 `#f7b99a`、柠檬 `#f4d66e`、抹茶 `#b3d79b`、薄荷 `#8ed6c0`、香芋 `#b7a2e2`；不强制覆盖已有主题选择。壁纸、用户头像、AI 头像可替换；不要写死个人图片或主题色。
- Cormorant Garamond 仅用于大号展示文字（约 20px 以上），如纪念日数字、日历时间、欢迎语和用量大数字；纪念日字重 500（对应 Tidal Echo 的主页）。小标签、小数值、日期、AI 头像标签与中文使用系统无衬线字体（苹方/微软雅黑等），数字使用等宽齐线形式。英文字体在 `assets/fonts/` 本地托管；思源宋体旧资源暂保留但不再加载，许可随仓库保留；开屏仍使用已选定的 Distant Stroke。
- 动画轻而自然：按压反馈、页面切换、弹窗/抽屉、侧边栏、选中和组件换位。遵循 `prefers-reduced-motion`，不要一直摇晃或增加长等待。
- 所有页面的导航返回按钮统一为音乐页的无背景、无边框箭头，并通过 app-topbar 固定页头位置（手机侧边 16px、顶部安全区下 10px；页头 64px 加安全区，滚动时留在顶部），使用 `src/ui.js` 的 `backButton()` 与 `src/navigation.css`（标准 App 页头由 appPageHeader 复用）。页头背景完全透明，无填充、边框、阴影、模糊或实色降级遮罩，不随外观透明度／模糊变化；不要恢复顶部矩形遮罩。统一 20px SVG、44×44px 点击区域、昼夜文字色和键盘焦点；音乐的返回／向下收起共用同一组件，保留 280ms 转向、原按钮／SVG 节点及减少动态效果支持。日历换月等内容操作的箭头不属于导航返回，不要混用动作。
- 预览图应来自实际代码界面；参考图只是方向，不代表已实现。不要把用户提供的截图、立绘或头像擅自放入公共仓库。

## 当前已实现的交互

### 导航和主页

- 默认打开桌面；底部快捷区依次包含消息（chat）、记忆、外观、设置四个独立图标，禁止增加整块胶囊／圆角底座、边框、阴影或底座模糊；与桌面四列图标逐列对齐。已删除代表主页的房子图标，不显示中文或选中圆点，保留无障碍名称和触摸／键盘入口。Dock 仅桌面显示；所有非桌面页面均全屏、不保留底部快捷栏。记忆和设置页使用与独立 App 相同的返回桌面页头；聊天与会话列表沿用侧栏导航。
- 桌面显示日记、音乐、图库、预设、世界书、档案六个 App；外观仅从底部快捷栏第三个入口打开，不在桌面或添加列表重复展示。桌面 App 图标占 1×1，四列排列，日间灰黑 Glass 图案、夜间银白 Glass 图案，固定乳白／深灰磨砂外框与背景，不再绑定外观的透明度和模糊滑块；与底部入口共用 launcher-tile 的尺寸、圆角和材质。每个入口可打开独立页面，左上返回主页，App 内隐藏底栏。新数据默认在第二页放 App；已有布局优先使用空页或新增页，不重排原组件，最多 12 页。
- App 图标复用长按菜单（打开 App、编辑主页、移除）、拖拽排序/跨页、Alt+方向键和入口恢复。移除只设置 home.hiddenApps，不删除配置或内容；满页阻止移动/恢复并提示腾出空间，取消拖动不保存；拖拽可经过已满页面继续翻页，未找到空位时回到图标原页。1×1 与大组件混排时自动避开碎片空位，保持 4×6 网格。
- 外观 App 已完整接入原有主题、夜间模式、透明度、模糊、壁纸和两种头像设置；系统设置移除外观分组，保留陪伴者、模型、插件、储存和用量。图库展示本机壁纸、头像和聊天图片；档案展示现有双方资料与数量。世界书与预设已重做为酒馆概念下的本机配置编辑器，细节见下文。联网音乐曲库/同步一起听、相册管理和模型上下文尚未接通，不要把配置界面当作运行服务。
- 音乐 App 已按手机音乐 App 的布局重构：首页「一起听」头像卡 + 双列方形歌单，封面右下角为播放三角；歌单详情包含封面、名字/介绍、播放全部、搜索和歌曲行；底部固定小播放器可打开黑胶详情。播放页有唱臂、唱片、封面、收藏、进度条、上一首/下一首、循环/随机和队列抽屉。保留全局壁纸，不添加参考 HTML 的装饰背景圆，玻璃表面沿用统一透明度/模糊。旋转只跟随真实播放，暂停时停转，减少动态效果时不旋转。
- 音乐首页与歌曲详情页共用「一起听」状态：双方头像靠近/轻微重叠，两侧从头像外缘垂下耳机线，SVG 线条通过竖向渐变向底部淡出；下方展示「相距…公里，一起听了…分钟」。详情页状态位于页头下方、唱片上方，短屏缩小头像/唱片及间距；已删除旧的「让旋律陪着这一刻」小头像行和「本机音乐」页脚，载入状态显示在页头，缺失音频时仍保留补回文件入口。头像沿用全局已保存图片。状态数据由 UI 的 together.distanceKm / together.elapsedSeconds 接收，缺少/非法值显示短横，0 值正常显示；距离最多两位小数，时长按完整分钟显示。目前无位置/同步一起听服务，默认两项为 null，不编造距离或时长，不请求定位，也不写入音乐持久数据。
- 音乐首页顶部标题为小写 music；页头返回、搜索和更多按钮为无填充/无边框图标，保留 44px 点击区域与键盘焦点。音乐内部更新保留页头、返回按钮及 SVG，左箭头与下箭头使用同一 SVG 旋转 280ms，快速反向切换连续过渡；减少动态效果时直接切换。保留页头后，音乐自己的按钮点击只由音乐控制器处理一次，避免变更后的返回动作再次触发全局导航。歌曲列表/队列不展示序号和当前播放耳机标记，保留当前歌曲的背景高亮；首页 Playlists 右侧不展示歌单总数。
- 首页头像卡不再显示顶部耳机图标／「一起听」标题及「添加本机音乐」按钮，保留一起听的无障碍名称、头像、耳机线、距离／时长、歌曲信息和进度线；歌曲信息上提约 22–24px，卡片随内容收紧。音乐导入仍可从歌单或空播放器进入。详情页头像状态下移 8px，唱片与歌曲信息下移 16px；高度不超过 700px 时分别缩减为 6px／10px，通过现有弹性留白保持播放控件的位置，避免挤出首屏。
- 音乐支持用户添加本机文件（单首最多 80MB、曲库最多 500 首，支持程度取决于浏览器音频解码）、新建/管理/删除歌单、收藏歌曲、编辑曲名/歌手/封面、删除歌曲及补回缺失文件。默认曲库为空，仅提供我喜欢的音乐/全部音乐/最近播放三份真实集合，不导入参考稿的假歌名、假数量、歌词或一起听时长。头像陪伴区是界面设计，尚无多人或 AI 音频同步。
- `music` 状态保存歌曲元数据、歌单、当前歌曲 ID、队列和循环模式，沿用同源 localStorage 与 v1/v2 JSON 备份兼容；旧备份缺字段时补空曲库。实际音频独立保存在 IndexedDB `chenxin.music.files.v1` 的 files 表，不放入 localStorage 或 JSON 备份。刷新不自动播放；同浏览器原文件仍可播放，换设备恢复歌单后可用「重新选择音乐文件」补回原 ID，保留曲名/封面/歌单。导入完整备份时取消播放和未完成的旧播放请求，避免播放已替换的曲库。
- 主页顶部原来的品牌/「我们的主页」标题区域已删除。
- 日记 App 已按月历 + Timeline 时间线重构：保留全局壁纸与玻璃材质，不添加参考稿的背景装饰圆。支持换月、回到今天、日期选择与记录高亮、心情色点、同日多篇、本机新建/编辑/删除；月历支持方向键与 Home/End。右下角写日记按当前选中日期创建。小字使用 UI 无衬线字体，月份/Timeline/时间线大日期使用 Cormorant。未创建记录时展示空状态，不预置示例日记。
- 日记字段 `diaryEntries` 随现有 JSON 备份导入/导出；每篇保存 id、date、title、content、mood、created、updated，标题最多 80 字、正文最多 12000 字。日期使用本地日历日，修改保留创建时间；旧 v1/v2 备份缺字段时补空数组。保存失败回滚状态并保留编辑内容。日记仅保存在本机，尚无 AI 自动写日记或云同步。
- 纪念日透明无边框，占 4×2：左侧开始日期（14px，位于数字上方）、放大的衬线数字及数字右下侧 days；右侧两个独立圆头像并排，各自上方为连续圆滑短尾巴的中性高透玻璃气泡（SVG 主体和尾巴为一个路径，非单独三角形）；气泡背景只随昼夜切换，数字、气泡文字、日期和头像占位文字在日间固定深灰蓝，夜间随主题色变化。头像素材沿用用户自己的图片。原标题与下方说明不再展示或提供编辑，旧数据仍保留在存储及备份中。
- 纪念日默认开始日期为 2026-07-12；旧数据的 2026-10-07 一次性迁移为该日期，其他已有日期保留，迁移后仍可自由编辑。日期上移至数字上方，保留与数字之间的留白。
- 日历遵循用户提供的玻璃卡片示例：实时 24 小时时间、星期/日期标签、分隔线、前一周/本周/后一周共 21 天，突出今天，字号在原示例基础上略微放大；跨日刷新，跨月/跨年正确排列，保留星期显示设置与组件名。
- 主页每页保留 4 列 × 6 行；每格高度由容器宽度计算，宽高相等，App 图标占 1×1，不再按屏幕高度拉伸。纪念日占 4×2，今天、便签、心情、记忆收藏各占 2×2 且严格为 1:1。多余屏幕高度留作桌面留白，短屏编辑模式允许纵向滚动，不压扁组件。按组件顺序寻找空位排列，不重写原分页数据。
- 便签、心情、记忆外层统一使用接近日历的高透玻璃，不显示左上方名称（无障碍名称保留）。便签取消蓝色折角，改为前后大双引号；点击编辑只显示便签内容，不显示组件标题输入，旧标题数据保留；底部日期表示今天（不表示最后修改时间）；心情采用大号 SVG 表情和四色选择点，沿用开心/平静/疲惫/想念四种本机状态；记忆采用叠放卡片，展示用户选中/最近的有效记忆、真实创建日期和有效记忆数量，没有记忆时显示空状态。小字仍使用系统无衬线字体，不照搬示例的宋体或示例内容。
- 长按或右键主页组件，在组件附近弹出「编辑内容、编辑主页、移除」菜单；支持键盘入口、方向键、Escape 与点击外部关闭。编辑内容只打开当前组件的编辑抽屉。
- 「编辑主页」进入全局布局模式，直接拖拽组件排序（含纪念日），使用角落的 × 移除，不再提供选中模式或箭头排序，也不打开内容编辑。底部「编辑主页」入口已按用户要求删除，长按组件菜单仍可进入编辑。
- 主页支持新增分页（最多 12 页）、左右滑动和圆点切换；左右箭头已删除，分页圆点保留，底部留白收紧。编辑模式拖到左右边缘或分页控件停留约 650ms 可翻页并移动组件；拖拽中显示浮起的组件与原位占位，释放才保存，取消不保存。翻页只更新当前页内容和分页圆点，保持壁纸、底栏、主页容器与编辑工具栏的 DOM；动画仅做 18px 横向位移，140ms，不再淡入，快速连续翻页会取消上一段动画，减少玻璃层闪烁。
- 键盘可用 Alt+上下调整页内顺序、Alt+左右移到相邻页。
- 菜单按组件实际位置水平居中并避让屏幕边缘，上半屏优先向下、下半屏优先向上弹出；基于未变换的尺寸定位，避免开场动画影响坐标。
- 纪念日日期、双方名字/头像、气泡文字，以及各组件设置均可原地修改；取消不保存。移除只隐藏并保留内容，可重新添加（含纪念日）；支持网格内拖拽排序及跨页移动，不是任意像素位置的自由布局。
- 主页组件配置已从设置页移除。

### 对话和会话

- 左上是侧边栏折叠按钮，不是返回按钮。侧栏有用户资料、导航、置顶与历史会话、新建入口。
- 完整会话列表支持搜索标题/消息、时间排序、置顶、重命名、删除。
- 右上 `✦` 是模型选择；冗余的「…」按钮已删除。
- 输入框与侧边栏为高透水玻璃视觉模拟：中性低透明填充、亮边、柔和反光、背景模糊与饱和度，昼夜分别适配；输入草稿、附件、消息保存和侧栏导航行为保留。
- 输入框自动增高、最多约六行；发送图标为纸飞机，工具栏有 `+` 和表情入口。
- 附件、表情、模型选择和思考详情为从屏幕底部升起的抽屉，覆盖输入框，背景模糊、暂不可交互。与音乐队列、歌曲编辑和歌单编辑共用玻璃材质、顶部横条、圆角、间距与列表卡片样式；所有这些抽屉不再放右上角 ×。支持点横条、遮罩、Escape、下拖横条收起与短拖回弹；横条保留键盘关闭入口，关闭后恢复焦点，聊天背景解除 inert。队列内打开歌曲编辑复用同一个 dialog，不重新关闭再弹出。
- 附件入口：相机、图片、文件、MCP 配置。相机行为取决于设备浏览器。
- 颜文字/表情包可收藏、编辑或管理，并有收藏/最近使用。颜文字在光标位置插入；表情包另支持备注、图片上传、文字／TXT／JSON／DOCX 导入、自定义分类与多选移动／删除，见文末最新说明。
- 用户消息长按菜单：复制、编辑消息、回滚至此、创建分支、删除。
- AI 消息长按菜单：复制、创建分支、删除。桌面支持右键、Shift+F10；滚动会取消长按。
- 回滚保留选中消息、移除后续消息，操作前确认；分支复制至选中消息，原会话保留；编辑保留附件，不重新生成已有回复。
- AI 消息有思考详情入口，正文在底部抽屉显示 `reasoningSummary`。只展示服务明确提供的摘要或过程信息，没有数据时显示空状态，不编造思维链。

### 记忆与设置

- 记忆可手动添加、搜索、修改、删除，从聊天收藏；短期为 1/7/30 天，永久记忆不设期限。
- 到期记忆保留在已到期分类，不静默删除。
- 外观中的玻璃透明度滑块从左到右为 70% → 0%：左侧更透明，右侧更实，input 仍保存旧的 appearance.opacity（不透明度 30–100），显示值为 100 - opacity；默认值和旧备份值不重置。新增范围可保存 100（显示 0%），旧的 95 仍保持 95（显示 5%）。
- 小组件、SVG 纪念日气泡、聊天气泡/输入框、侧栏、设置/独立 App 面板、菜单及编辑弹窗的玻璃填充已接入 --glass-alpha、--glass-soften、--glass-solid，会实时变化。桌面及底部入口图标使用独立固定材质，除夜间模式外不跟随外观调节。材质映射保留原默认 60 的清透视觉；向 30 减淡原填充，向 100 增加中性实色底层，0% 时玻璃表面不透明。亮边与反光保留，正文/图标不使用整体 opacity，背景模糊仍独立由 --glass-blur 控制。新增普通玻璃表面需要使用这套材质变量；入口图标为用户明确要求的例外。模态遮罩深浅保持原有层次。
- 系统设置包含角色、API/模型配置、MCP/插件配置、数据储存和用量；外观已迁入独立 App（底部快捷栏第三个入口）；JSON 完整备份导入/导出。分组卡片为高透玻璃，保留壁纸；已接入统一透明度控制。外观 App 的背景模糊 0–40px 统一控制小组件、纪念日气泡、聊天气泡/输入框、侧栏、菜单/弹窗和已有模糊遮罩（桌面与底部入口图标除外），通过 --glass-blur 实时更新；0 表示不模糊，保存与备份字段沿用 appearance.blur。透明无材质的纪念日主体不额外加模糊。滑块填充使用主题色、未填充为淡主题色染色，支持键盘；自定义颜色以圆形色块和色值标签呈现，仍使用原生取色器。

## 功能边界：务必区分 UI 和真实服务

- 目前仍是纯前端、本机原型，没有应用后端、真实模型调用或 AI 自动回复。
- 发送只保存本机消息；API 密钥输入禁用。模型选择、MCP/插件入口目前保存配置，不执行服务。
- 图片和表情包压缩后保存在本机。普通文件只保存名称、类型、大小，不保存文件内容，不上传、不让模型读取。
- 附件最多 6 项、单项 10MB；图片处理另有类型和大小检查。未发送附件为临时草稿，刷新会消失。
- 尚无账号登录、订阅额度对接、自动记忆提取/上下文检索、MCP 执行、语音接入、云同步、后台通知、APK 或 PWA 安装/离线缓存。
- 用量目前显示本机数量，不显示虚构 Token/费用。
- 用户已在 ElevenLabs 选好名为 `aster` 的自定义声音，想未来接入；仓库尚未集成它。不要混用另一个角色的声音或假设聊天语音已经接通。

## 表情包备注、导入与分类管理（2026-10-17）

- 图片／表情包消息不显示图片下方的文件名或备注，保留 alt 和消息数据中的说明；用户自行输入的正文与普通文件名称照常显示。
- 新模块 src/expressions/：model.js 管理规范化、导入解析、分类与多选操作；files.js 读取 TXT／JSON／DOCX；view.js 复用表情包／颜文字面板；controller.js 处理共享抽屉、上传草稿、分类长按与批量管理；style.css 在主样式之后加载，避免旧表情网格规则覆盖短屏布局。app.js 继续管理发送与颜文字插入。
- expressions.categories 保存 [{id,name}]，每个表情包保留原 id/value/name/favorite/used 并增加 note 和 category；未分类用空字符串。旧图片名称自动成为备注，未知分类归未分类；旧颜文字、会话、主页和外观不重置。发送表情附加 kind:'sticker'、note 和图片 data；消息是当时的独立副本，删除收藏／分类不会影响历史消息。
- 上传单张图片时必须填写 1–200 字含义；JPG／PNG／WebP 压缩至最大边 512px，使用带透明通道的 WebP（浏览器可回退 PNG），GIF 在 850KB 内保留原文件与动画。库最多 200 项，分类最多 50 个且名称 1–30 字。上传与保存失败保留草稿，并回滚持久状态。
- 文字支持每行「含义：HTTPS 图片网址」或含义与网址分为两行，兼容中英文冒号、UTF-8 BOM 和网址内部冒号；JSON 支持 [{meaning,url}]、[{note,value}]、{stickers:[...]} 或 {含义:网址}。导入先预览再确认；格式错误／超限时整体不写入，同备注同网址重复项跳过。
- TXT／JSON／DOCX 文件上限 2MB。DOCX 仅本机解压 word/document.xml 并提取文字，不执行内容、不读取图片／宏／外链；使用浏览器 DecompressionStream('deflate-raw')，缺少支持时提示另存为 TXT／JSON。网址表情只保存 HTTPS 原链接，不额外下载；拒绝脚本、SVG data、账号密码 URL 等来源。壁纸与普通图片附件仍只接收原本的图片 data URL。
- 分类可新增，长按／右键／Shift+F10 分类打开重命名与删除抽屉，当前分类旁的更多按钮提供触屏／键盘替代入口。删除分类将其表情包移至未分类；管理模式显示选择数量与勾选状态，全选仅作用于当前可见列表，可批量移动／删除，删除有确认。
- 表情包、分类、导入、移动／删除及颜文字编辑均沿用共用玻璃抽屉和拖拽横条，无右上角 ×；支持横条、下拖、遮罩、Escape 与焦点恢复。收藏／分类／多选通过局部更新保留面板及网格滚动；短横屏整体滚动，防止管理栏压住图片。面板支持昼夜及全局透明度／模糊设置。
